# Egypt Event Hub

Create a modern, premium, responsive event ticketing website prototype for an Egyptian event platform.

The goal is to create a polished visual demo that I can show to a potential client. This is ONLY a frontend prototype for now — no real payment gateway, database, authentication, or backend is needed.

Brand

Use a modern Arabic-first design with a premium dark theme.
Primary colors: black / very dark charcoal with a vibrant purple or electric blue accent.
Use clean Arabic typography and excellent spacing.
The website should feel similar to a professional ticketing platform, not a generic template.

Important UX

Fully responsive on desktop, tablet, and mobile.

Arabic RTL layout.

Smooth hover effects and subtle animations.

Modern cards with rounded corners.

Professional spacing and hierarchy.

Make buttons and navigation feel interactive.

Clicking "احجز الآن" should navigate to the checkout page.

Clicking an event card should open the event details page.

Use realistic placeholder images instead of broken image URLs.

Make the entire website feel like a real startup/product ready to launch.

Do not add unnecessary features.
Focus on making the prototype visually impressive, clean, modern, and convincing for a potential client.
